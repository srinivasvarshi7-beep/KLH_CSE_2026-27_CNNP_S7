# Computer Networks Practical (CNNP)

## CN Skill 1 – Encapsulation Builder

**Aim:** To capture and analyze network packets and understand Ethernet, IP, TCP, and UDP encapsulation.

**Tools:** Wireshark, Windows.

**Summary:**
- Captured and analyzed network traffic.
- Inspected TCP, UDP, Ethernet, and IP headers.
- Applied protocol display filters.
- Calculated packet overhead and network efficiency.

**Result:** Successfully understood network encapsulation and packet structure. Theoretical network efficiency calculated was **96.28%**.

## CN Skill 2 – Three-Point Capture

**Aim:** To capture and analyze packets at Host1, Router, and Host2 in a virtual network.

**Tools:** Ubuntu WSL2, Wireshark, TShark, Netcat, iproute2, and Traffic Control.

**Summary:**
- Created three network namespaces and configured routing.
- Established communication between Host1 and Host2.
- Simulated 20 ms delay and 1% packet loss.
- Captured packets at all three network points.
- Transferred TCP data using Netcat.
- Analyzed TTL, TCP payload, and merged captures.

**Result:** Successfully implemented three-point packet capture and analyzed network communication using Wireshark.
